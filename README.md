# Windows PowerShell Tool Building Workshop

## Overview

Welcome to the **Windows PowerShell Tool Building Workshop**! This workshop is designed to provide a structured learning path for participants to develop professional PowerShell tools. It covers fundamental and advanced PowerShell scripting concepts, error handling, debugging, parallel execution with runspaces, Git version control, and even graphical user interface (GUI) development using PowerShell.

## Workshop Modules

The workshop is divided into multiple modules, each focusing on a specific aspect of PowerShell tool building:

1. **Knowledge Refresh** - Review fundamental PowerShell concepts to ensure a strong foundation.
2. **Advanced Functions** - Learn to create robust and reusable PowerShell functions.
3. **Mastering Parameters** - Understand advanced parameter attributes to make scripts more dynamic and user-friendly.
4. **Classes** - Introduce object-oriented programming concepts to PowerShell.
5. **Error Handling** - Implement best practices for handling errors in PowerShell scripts.
6. **Debugging** - Learn techniques to troubleshoot and debug PowerShell scripts efficiently.
7. **Git Introduction** - Understand basic Git operations to manage and track changes in scripts.
8. **Git Intermediate** - Explore advanced Git functionalities for version control.
9. **Runspaces** - Optimize script execution using concurrent processing with runspaces.
10. **Create a GUI in PowerShell** - Develop interactive graphical user interfaces using PowerShell.

## Pre-Built Demos

All demo scripts in this workshop are **pre-built** for easy use. Participants can execute the provided scripts during the workshop and revisit them later to reinforce their learning. The structured examples ensure hands-on practice without the need to manually create scripts from scratch.

## Prerequisites

All participants should be graduates of the **Windows PowerShell: Foundation Skills** workshop to ensure they have the necessary background knowledge for this advanced training.

## Getting Started

To begin the workshop:
1. Clone this repository:
   ```powershell
   git clone https://github.com/gadla/Public-WorkshopPlus-Windows-PowerShell-Tool-Building.git
   ```
2. Navigate to the relevant module folder.
3. Follow the documentation and run the provided scripts.

## Requirements

- Windows PowerShell 5.1 or later (recommended: PowerShell 7+)
- Git installed for version control modules
- A text editor (e.g., VS Code, PowerShell ISE)

---

By completing this workshop, participants will gain hands-on experience in PowerShell scripting, debugging, and tool development, making them more efficient in automating administrative tasks and developing powerful automation tools.
